# Asset Attribution & Provenance

The tile images and board assets used in this project are derived from a fan-made project recreating the classic board game *DungeonQuest* (originally published as *Drakborgen* in 1985, and later by Games Workshop and Fantasy Flight Games).

## Source Information

- **Source Forum/Thread:** [DakkaDakka Forum - DungeonQuest Remake](https://www.dakkadakka.com/dakkaforum/posts/list/761305.page)
- **Original Content Creator:** Valnar Nightrunner (DakkaDakka User)
- **Alternative/Portfolio Gallery:** [Valnar Nightrunner's DeviantArt Gallery](https://www.deviantart.com/valnarnightrunner/gallery/66868140/Dungeonquest-Remake)
- **Original Publication Date:** Starting July 2018

## Description of Original Assets

The source materials include high-quality, printable sheets created by the author to replicate and modernize components from the Games Workshop edition of *DungeonQuest* and *DungeonQuest Catacombs*. These include:
- 135 dungeon tile sheets
- Treasure counters & marker tracks
- Various encounter, monster, crypt, and search card decks

## Modifications & Processing

The assets in this repository have been extracted and processed from the original community sheets to serve as individual tile sprites suitable for a web-based/browser game layout.
